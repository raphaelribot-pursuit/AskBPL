## How to compare a new run with this baseline

`askbpl-eval --compare` compares role lenses and refuses two runs with the same role. To compare a change against this
baseline, use `scripts/compare_runs.py` (read-only), from `packages/orchestrator`:

```
python ../../scripts/compare_runs.py eval_data/results/eval_20261031T184215Z_e3c8add_live_default-staff.json <new client+team run>.json
python ../../scripts/compare_runs.py eval_data/results/eval_20261031T185013Z_e3c8add_live_default-staff.json <new robustness run>.json
```

It lists every question whose status, per-repeat outcomes or cited documents changed. On 2026-10-31, the morning
(8-document) run and this baseline were identical on all 37 client and team questions.
